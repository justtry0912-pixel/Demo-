# Prompt 03 — Production Plan or Motion Code

Use after selecting a storyboard.

---
Turn the approved storyboard into a production-ready implementation plan for **[TOOL/STACK]**.

First, confirm what can actually be produced with the selected tool. If the tool is unknown, compare the most practical options briefly and ask me to choose.

Deliver:
1. Project/file structure
2. Asset inventory, naming convention and missing-assets list
3. Scene-by-scene build instructions with durations and transitions
4. Editable controls for text, logo, colors, product image, CTA and scene timing
5. Typography, easing, camera/light and compositing notes
6. Audio timing and mix notes
7. Export settings for [PLATFORM / ASPECT RATIO / RESOLUTION / FPS]
8. How to preview, render and troubleshoot

If writing code, provide complete files rather than isolated fragments. Add comments for editable values, setup commands, dependencies, and a README. Avoid inaccessible or unlicensed assets; use clearly labeled placeholders. Do not claim a render or test succeeded unless you actually ran it. Include a reduced-motion or static fallback where appropriate.
