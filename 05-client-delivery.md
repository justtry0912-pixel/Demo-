# Prompt 05 — Delivery and QA

---
Prepare a client handoff for this finished motion ad.

**Project:** [name]  
**Approved runtime and formats:** [details]  
**Files actually rendered:** [list]  
**Editable/source files included:** [list]  
**Known limitations:** [list]  
**Asset/claim review status:** [status]

Create:
1. A concise delivery message
2. A file manifest with format, resolution, frame rate, aspect ratio and intended use (leave unknown values marked “confirm”)
3. A quality-control checklist
4. A list of third-party assets and license records to archive
5. A clear note about any missing items or client approvals

QA: check spelling, logo/product consistency, safe areas, text legibility, timing, audio peaks, black frames, transition glitches, CTA, export dimensions, frame rate, compression and platform requirements. Never claim a check was performed unless it was performed.
